# Muhammad Abi Rafdi Portfolio

Personal portfolio website for Muhammad Abi Rafdi, a frontend developer focused on Vue.js applications, responsive interfaces, dashboard products, and REST API integration.

## Tech Stack

- Vue 3
- Vue Router
- Vite
- Bootstrap 5
- Custom CSS

## Pages

- Home: profile summary, highlights, and primary calls to action
- About Me: professional bio, contact links, and technical focus
- Experience: work history, core skills, and CV link
- Projects: selected project case notes and screenshots
- Gallery: curated personal and travel photos

## Development

Install dependencies:

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
